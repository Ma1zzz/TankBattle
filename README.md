# 坦克大战 · Tank Battle

一个纯 HTML + JavaScript 实现的经典坦克大战小游戏，单文件即可运行，无需任何依赖。

## 玩法

- 控制我方坦克消灭敌人，并**保护下方的基地（星标）**。
- 基地被击毁或我方生命耗尽，游戏结束。
- 每关敌人数量递增，还可能出现快速型、火力型等不同敌人。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 / `WASD` |
| 开火 | 空格 / `J` |
| 暂停 | `P` |
| 音效开关 | `M` |

> 手机等触屏设备会自动显示虚拟方向键与开火按钮。

## 运行

直接用浏览器打开 `index.html` 即可。

## 元素说明

- **砖墙**（棕色）：可被子弹摧毁。
- **钢墙**（灰色）：无法摧毁。
- **河流**（蓝色）：坦克无法通过，子弹可穿过。
- **草丛**（绿色）：可隐藏坦克。

## 道具

- ⭐ **火力**：提升射击速度（最高 3 级）
- ⛨ **护盾**：短时间内无敌
- 🚙 **生命**：额外一条命
- ✹ **炸弹**：消灭场上所有敌人
- ❄ **冰冻**：冻结敌人 5 秒

## 技术

- Canvas 2D 渲染（2 倍像素放大，复古风格）
- Web Audio API 音效
- 网格碰撞检测与四方向移动
